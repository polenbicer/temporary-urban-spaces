# Temporary Urban Spaces — Gümüşlük Field Notes

A visual field study of unfinished structures, everyday encounters, coastal thresholds, and ongoing transformation in Gümüşlük, Bodrum.

The website combines a scroll-led narrative with a complete 64-image field atlas. Its visual language is built around the geometry of urban plots, street axes, construction traces, and the colors found in the site photographs.

## Live site

[temporary-urban-spaces.polenbicer.chatgpt.site](https://temporary-urban-spaces.polenbicer.chatgpt.site)

## Development

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```

## Stack

- Vinext / React
- TypeScript
- Tailwind CSS
- Cloudflare Workers through OpenAI Sites
